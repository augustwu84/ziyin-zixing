# 🐣 字音字形小學堂

給國小學生練習語文競賽「字音字形」的小網站，手機、平板、電腦都能用。

## 功能

- **字音練習**：看詞語裡紅框框的字，用畫面上的注音鍵盤拼出讀音（聲母、介音、韻母、聲調）
- **字形練習**：看注音，從四個字裡選出正確的國字
- **慢慢練習／計時挑戰**：計時模式每題有秒數限制，答得快可以多拿一顆星
- **星星獎勵**：答對得星星，累積的星星會保存在這台裝置上
- **錯題本**：答錯的題目自動收進來，複習時答對一次就會移出
- **音效與朗讀**：答對答錯有音效；字形題可以按「念念看」聽詞語（字音題因為破音字容易被語音念錯，所以不提供朗讀）
- **題庫進度**：首頁顯示每個題本練過幾題、答對過幾題
- **耳耳收集冊**：原創角色「耳耳」共 30 隻，每完成 10 回練習解鎖一隻，會跳出鼓勵畫面；還沒解鎖的以灰色剪影顯示
- **家長後台**（`admin.html`）：登入後可以看每回練習的分數、答錯的題目、常錯題排行，也能修改密碼

## 雲端紀錄（Firebase）

家長後台的練習紀錄存在 Firebase Firestore：

1. 把 Firebase 網頁應用程式的 `firebaseConfig` 貼進 `firebase-config.js`
2. Authentication 開啟「匿名」與「電子郵件／密碼」登入，並新增後台使用者
3. 把後台使用者的 UID 填進 `firebase-config.js` 的 `ADMIN_UID` 和 `firestore.rules`
4. Authentication → 設定 → 已授權網域加入 `augustwu84.github.io`
5. Firestore 規則貼上 `firestore.rules` 的內容

後台登入時，帳號欄輸入後台使用者的電子郵件。

還沒設定好之前，練習紀錄會先存在練習的裝置上，設定完成後自動補傳。

## 題庫

目前收錄兩回試版，共 200 題：

| 題本 | 題型 | 題數 |
|---|---|---|
| 字音試題（六） | 字音 | 100 |
| 字形試題（七） | 字形 | 100 |

題目與答案轉寫自「語文競賽國小學生組字音字形試題」的答案卷。答案以試題卷上的答案為準；少數字的讀音後來在教育部審訂音中有調整（例如「包括」的「括」），這些題目也接受新版讀音。

新增題目只要編輯 `data.js`，照現有格式加一個題本即可。

## 本機執行

純靜態網站，不需要安裝任何套件：

```bash
python3 -m http.server 8765
```

再打開 http://localhost:8765 。
